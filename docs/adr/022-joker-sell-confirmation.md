# ADR-022: 상점 조커 판매 확인 UI

- **Status**: Accepted
- **Date**: 2026-04-01

## Context

현재 조커 판매(`sellJoker`)는 스토어에 함수가 존재하지만, 상점 UI에서 조커를 클릭하여 판매하는 흐름이 없다. 원작 발라트로에서는 상점 진입 시 보유 조커를 클릭하면 판매 가격을 확인한 뒤 확인 버튼으로 판매할 수 있다.

## Decision

### 판매 가격

- **판매가 = 구매가의 절반** — `sellPrice` 필드를 그대로 사용 (이미 `sellPrice = 구매가 / 2`로 정의됨)

### 판매 흐름

1. 상점 화면에서 보유 조커를 클릭
2. 해당 조커에 판매 확인 패널(인라인 또는 팝오버) 표시 — 판매 가격과 "SELL" / "CANCEL" 버튼
3. "SELL" 클릭 시 `sellJoker(id)` 호출, "CANCEL" 또는 다른 곳 클릭 시 패널 닫기
4. Eternal 조커는 판매 불가 — 클릭 시 판매 UI를 표시하지 않음

### 구현 위치

- **`pages/index.vue`** — 상점 phase에서 JokerSlots 영역에 클릭 이벤트 추가
- **`components/joker/Card.vue`** — 상점에서 클릭 시 확인 패널 emit 또는 내부 상태 관리
- **스토어 변경 없음** — `sellJoker()`는 이미 구현되어 있음

### 제약 사항

- 클릭 즉시 판매하면 안 됨 — 반드시 확인 단계를 거친다
- 플레이 중에는 판매 불가 — 상점(`shop`) phase에서만 활성화

## Consequences

**긍정적:**
- 조커 슬롯 관리 전략이 가능해져 빌드 유연성 증가
- 실수로 판매하는 사고 방지

**부정적:**
- 클릭 2번 필요하여 조작이 약간 느려짐 (의도된 트레이드오프)
